# STRATBOOK Consolidator

Инструмент для консолидации и дедупликации файлов тактических книг (Stratbooks) по CS2 в единый итоговый XLSX-файл.

## Описание

`consolidate.php` — автономный PHP-скрипт (версия v7, HARD DEDUPE), который:

1. **Читает** несколько XLSX-файлов Stratbook без внешних зависимостей (использует нативные `ZipArchive` и `SimpleXML`).
2. **Классифицирует** строки по секциям: стратегии (strategy), спавны (spawn), стенки (wall), гранаты (nade).
3. **Дедуплицирует** записи:
   - точное совпадение нормализованного текста;
   - расстояние Левенштейна ≤ 2 (`LEV_MAX_DIST`);
   - коэффициент Жаккара по токенам ≥ 0.85 (`JACCARD_HARD`);
   - пропуск структурно идентичных входных файлов (по SHA-1 хэшу структуры листов).
4. **Собирает** итоговый файл `STRATBOOK_FINAL.xlsx` с листом «СВОДКА» и картами в фиксированном порядке, раскрашивая ярлычки листов (tab colors).

## Поддерживаемые карты

`NUKE`, `TRAIN`, `ANCIENT`, `MIRAGE`, `ANUBIS`, `DUST 2`, `INFERNO`, `VERTIGO`, `OVERPASS`, а также листы гранат: `NADS ANUBIS`, `NADS ANCIENT`, `NADS TRAIN`, `NADS Mirage`, `NADS DUST 2`.

## Требования

- PHP ≥ 8.0 с расширениями `zip`, `simplexml` (libxml), `mbstring`.
- Внешние Composer-пакеты не требуются (`composer.json` пустой).

## Использование

Положите входные XLSX-файлы рядом со скриптом (список файлов задаётся в массиве `$files` в начале `consolidate.php`) и выполните:

```bash
php consolidate.php
```

Результат — файл `STRATBOOK_FINAL.xlsx` в той же директории. В консоли выводится отчёт: прочитанные файлы, добавленные/удалённые строки по каждому листу и количество записей по секциям.

## Настройка

В начале `consolidate.php`:

| Переменная | Назначение |
|---|---|
| `$files` | Список входных XLSX-файлов |
| `$outputFile` | Имя итогового файла (по умолчанию `STRATBOOK_FINAL.xlsx`) |
| `$sheetOrder` | Порядок листов карт в итоговом файле |
| `$tabColors` | Цвета ярлычков листов (ARGB HEX) |
| `$JACCARD_HARD` | Порог похожести строк по Жаккару (0.85) |
| `$LEV_MAX_DIST` | Максимальное расстояние Левенштейна для склейки (2) |
